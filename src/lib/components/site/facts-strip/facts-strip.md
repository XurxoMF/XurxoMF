# Facts Strip

Franxa destacada de catro datos clave para as fichas de proxecto.

Impórtase desde `$lib/components/site/facts-strip` e úsase como `FactsStrip.Root`. A prop `facts` recibe elementos `{ label, value }`; nas páxinas de proxecto deben proporcionarse exactamente catro e móstranse centrados nas súas columnas.
