# Facts Strip

Franxa destacada de catro datos clave para as fichas de proxecto.

Impórtase desde `#lib/components/site/facts-strip/index.ts` e úsase como `FactsStrip.Root`. A prop `facts` recibe elementos `{ label, value }`; nas páxinas de proxecto deben proporcionarse exactamente catro e móstranse centrados nas súas columnas.

Cada dato entra desde abaixo cun pequeno desfase respecto ao anterior. O trigger permanece no contedor exterior para non interferir coa transformación que mantén a franxa a ancho completo.
